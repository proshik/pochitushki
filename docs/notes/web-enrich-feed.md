# Доработки веб-UI «Обложки» (ветка `web-enrich-feed`)

## Запрос

Пользователь одобрил макет (claude.ai artifact `5sjNZUt1BBFvGH5GaotaTu`, исходники — `mock.css`,
`site/*-after.html`, `build.py` в scratchpad сессии макета). Перенести его в приложение:
блок А (контраст, фокус, размеры, полоса `co-band`, пост без заголовка, hero) и блок Б
(Б2 фильтр по меткам, Б3 группы по датам, Б4 возраст, Б5 сортировка, Б7 клавиши).

## Решения

- **Отображение поста без заголовка** — `CoverView.title`/`titleParts` (`CoverService`):
  URL без схемы и завершающего `/`, части через `<wbr>` после каждого `/`. Данные не меняются.
  Пустой заголовок считается отсутствующим.
- **Возраст и группы** считает `PostViewService` (локаль запроса, «сегодня» =
  `LocalDate.now()` JVM — тот же пояс, что у прежнего «лежит N дн.» в hero).
  Плюралы — `Plurals` + ключи `*.one/few/many` (RU) и `*.one/other` (EN).
- **Возраст** только у непрочитанных (`!isArchived`), на всех страницах с карточками.
  `old` с 30 дней. В hero — всегда `age old`.
- **Группы** только на `/` и `/all` (и их фрагментах). Стык страниц: фрагмент с `offset > 0`
  читает на один пост больше (с `offset - 1`) и считает группу предыдущего поста —
  нового параметра в URL нет.
- **Сортировка** — ключ `feedSort` (`newest`|`oldest`, дефолт `newest`) в `users.settings`;
  до контроллеров доезжает request-атрибутом из `JwtAuthInterceptor`, как `showOgCovers`.
  Действует на `/`, `/all`, их фрагменты и фильтр по метке. Hero от неё не зависит.
  Сохранение — `POST /api/v1/profile/settings`, после ответа перезагрузка.
- **Фильтр по метке** — `?label=ID` на `/` и `/all`. Пилюли — метки пользователя с ненулевым
  числом постов в разделе (на `/` только `post_label`, на `/all` обе связки). Фильтр
  применяется, только если ID есть среди пилюль; иначе (чужая, пустая, мусор) — игнор, без 400.
  Сентинел несёт `&label=ID`. Hero при фильтре скрыт. Счётчик в шапке страницы — общий.
- **Клавиши** — только `app.js`, по `event.code`; нажимают существующие кнопки карточки
  (`data-kbd-archive`, `data-fav-btn`, `data-action="labels-show"`, ссылку заголовка).
- Палитра `cv-*` не меняется.

## Сценарии (тесты)

- старые `settings` без `feedSort` читаются как `newest`; неизвестное значение в PATCH → 400;
- DAO: сортировка `oldest`/`newest` с offset; фильтр по метке, в т.ч. архивные посты на `/all`
  при совпадающих id в двух таблицах;
- `/?label=мусор|чужая|пустая` → всё, без 400; при фильтре нет hero;
- заголовок группы не повторяется на стыке фрагментов;
- склонения RU/EN; отображение URL без заголовка.

## План

1. CSS из макета → `app.css` по разделам.
2. `CoverView.title` + фрагмент заголовка в шаблонах.
3. `Plurals`, `PostViewService` (возраст, группы), i18n.
4. `feedSort`: модель, интерцептор, PATCH, DAO (сортировка + фильтр), контроллеры, фрагменты.
5. Фильтр по меткам: `LabelDao`, шаблоны.
6. Клавиши и подсказка: `app.js`, шаблоны всех страниц со списком.
7. Тесты, AGENTS.md/README, проверка UI глазами (1440/390, светлая/тёмная), ревью.
